## 每份指南包含什麼

- **基本資訊**：訂房事實（確認碼、PIN、日期、房型、人數、房價、取消政策），一律照抄訂房 PDF
- **交通與位置**：從最近車站的步行動線、時間、拖行李注意事項
- **館內設施**：早餐、大浴場、洗衣、Wi-Fi、行李寄放的**時間與費用**
- **周邊生活機能**：步行 10 分鐘內、這幾天真的會用到的便利商店、超市、餐廳
- **本次行程使用規劃**：對應到實際日期的入住、早餐、出發、退房時間
- **聯絡確認信件**：四個情境（行前確認／入住與鑰匙／抵達時間變更／行李寄放）的**英文與日文各一封**，放在 code block 內可整段複製
