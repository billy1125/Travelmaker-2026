# Travelmaker-2026

2026 日本岡山・倉敷・尾道旅遊規劃（9 天 8 晚，08/28–09/05）

## 行程概要

- **去程：** IT214｜08/28 11:30 桃園 → 15:05 岡山桃太郎機場
- **回程：** IT215｜09/05 15:55 岡山桃太郎機場 → 17:40 桃園
- **住宿：** 岡山 3 晚（Super Hotel 站東口）→ 尾道 5 晚（Yutori by b hotel）
