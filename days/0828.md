# 08/28（Day 1）抵達岡山

- **住宿：** 岡山站周邊
- **航班：** IT214｜11:30 桃園出發 → 15:05 岡山桃太郎機場落地
- **岡山機場與車站間交通**：[岡山桃太郎機場官方（繁中）— 巴士交通](https://www.okayama-airport.org/tw/access/bus)

## 時間表

| 時間 | 動作 |
|---|---|
| 08:20 | 台北車站（A1）搭機場捷運直達車（約 39 分）。 |
| 09:00 左右 | 抵達第二航廈（A13），辦理報到、通關。 |
| 11:30 | IT214 起飛。 |
| 15:05 | [岡山桃太郎機場](https://www.google.com/maps/search/?api=1&query=岡山桃太郎空港)落地。 |
| 15:05–15:50 | 入境審查、提領行李、海關通關（國際線，預留 45 分鐘）。 |
| 15:50 左右 | 出到達大廳，前往 [2 號站牌](https://www.google.com/maps/search/?api=1&query=岡山桃太郎空港バス乗り場)。 |
| 16:00 左右 | 搭乘利木津巴士（IT214 台北航班加班車，或下一班定期車）。車程約 30 分。票價 **1,000 円**，可刷 IC 卡或在售票機購票。 |
| 16:30 左右 | 抵達[岡山站西口](https://www.google.com/maps/search/?api=1&query=JR岡山駅)，前往飯店 Check-in。 |

> ※ 班次以出發前最新時刻表為準，詳見 `transportations/OKJ_OkayamaStation.md`。
