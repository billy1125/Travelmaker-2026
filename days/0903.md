# 09/03（Day 7）島波海道單車日

- **住宿：** 尾道

## 行程

半日到一日版單車路線：

1. [尾道站](https://www.google.com/maps/search/?api=1&query=JR尾道駅)出發，搭渡船到[向島](https://www.google.com/maps/search/?api=1&query=向島+尾道)
2. 騎行向島
3. 渡船到[因島](https://www.google.com/maps/search/?api=1&query=因島+広島県)，騎行因島
4. 體力好可繼續到[生口島](https://www.google.com/maps/search/?api=1&query=生口島)
