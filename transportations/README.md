# 交通指南總覽

現場會拿出來看的路段與車站指南。原則是**寫會影響行動的事實，不寫會過期的清單**——除非某條路線的班次空窗本身就是行程的硬限制（例如機場巴士與吉備線），否則只寫班距，完整時刻表給官方連結。

## 幾個最容易踩到的坑

- **岡山站的月台分三組**：山陽本線 1–4 番、**宇野線 5–8 番**（09/06 直島）、**吉備線 9・10 番**（09/07 吉備津）。清晨趕 05:49 首班車時最容易走錯
- **倉敷站置物櫃只收 100 円硬幣**，大型 ¥700 要 7 枚，且僅 35 個。08/31 與 09/05 兩次都要用
- **岡山路面電車的「郵便局前」（住宿最近站）在清輝橋線**，該線不停「城下」。去後樂園、岡山城要在柳川轉東山本線，實務上不如直接走路
- **宇野港有兩個乘船處**（渡輪與旅客船相距步行約 3 分），買票前先確認船種
- **機場巴士與吉備線的班次空窗是硬限制**，這兩份指南裡的時刻表要在出發前重新核對——9 月版機場巴士時刻表至今未公告
