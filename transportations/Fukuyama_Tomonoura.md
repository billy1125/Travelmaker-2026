## JR 福山站

| 項目 | 內容 |
|------|------|
| 停靠 | 山陽新幹線（含部分のぞみ、ひかり、こだま）＋ JR 山陽本線、福鹽線 |
| 出入口 | **北口＝福山城口**（福山城就在站旁）／**南口＝ばら公園口**（巴士總站、往鞆之浦的方向） |
| 往鞆之浦 | 南口出站即巴士總站，**5 號站牌** |

**投幣式置物櫃**

| 位置 | 費用 | 使用時間 |
|------|------|----------|
| 1F 在來線改札**內**（新幹線改札口附近、3・4 番月台樓梯旁） | 依尺寸 | 05:00–24:00 |
| 1F 改札**外**（出改札左手邊，北口／福山城口側） | 小 500 円／中 700 円／大 900 円 | 首班～末班車 |
| 站前戶外（北口與南口各有） | 依尺寸 | **24 小時** |

- 站內外合計約 4 處、167 個櫃位；南口出站右側（Doutor 咖啡前）有較多可放行李箱的大型櫃
- 09/04 為輕裝日歸，通常用不到；若當天想先寄放伴手禮再出發可用

> ⚠️ **夜歸日要注意改札外置物櫃的使用時間。** 改札外那組寫的是「首班～末班車」，20:00 之後回到福山轉車時不保證還能開櫃；真要寄放請用**站前戶外 24 小時**那組。

## 鞆鉄巴士（福山駅前 ⇄ 鞆港）

| 項目 | 內容 |
|------|------|
| 路線 | 鞆線（福山駅前 ～ 鞆港） |
| 乘車處 | 福山站南口 **5 號站牌** |
| 所需時間 | 約 30 分鐘 |
| 票價 | 「鞆の浦」**580 円**（小兒 290 円）／「鞆港」**620 円**（小兒 310 円） |
| 付款 | 現金與 IC 卡**同價**；可用 ICOCA、Suica、PASMO 等全國相互利用 IC 卡 |
| 搭乘 | **後門上車、前門下車** |
| 洽詢 | 鞆鉄道株式会社 **084-952-3100**（福山營業所） |

**在哪一站下車**

- **「鞆港」**：離[常夜燈](https://www.google.com/maps/search/?api=1&query=鞆の浦常夜燈)最近，本次行程以港口與老街為主，**去回都建議用鞆港**
- 「鞆の浦」：距仙醉島渡船場步行 3–4 分，也是[歴史民俗資料館](https://www.google.com/maps/search/?api=1&query=鞆の浦歴史民俗資料館)（步行 5 分）與[医王寺](https://www.google.com/maps/search/?api=1&query=医王寺+鞆の浦)（步行 15 分）較近的一站
- 「安国寺下」：較前面的站，走到常夜燈要多花時間

> ⚠️ **同一個站牌會來「竹ヶ端行」的班次（一天約 5 班），那班不到鞆之浦。**上車前務必確認車頭是「鞆港行」或「鞆の浦行」。

> ⚠️ **定期觀光巴士不適用。**鞆の浦定期觀光巴士僅夏季週六日與國定假日運行（2026 年至 7/20 止），09/04（週五）不在運行範圍，只能搭路線巴士。

### 接續：福山 → 尾道（JR 山陽本線，糸崎・三原方面）

|---|---|---|---|
| 19:28 | 20:00 | **20:23** | 約 **20:45** |

> ⚠️ **19:28 那班到福山後有 23 分鐘轉乘時間，是三個選項裡最從容的。** 20:18 那班只有 12 分鐘，巴士誤點就會掉到 21:20，尾道抵達延到約 21:45。

## 本次行程使用規劃（09/04 Day 6・停留到夕景）

**當日天文時刻**（北緯 34.38°／東經 133.38°，2026/09/04）：

| 項目 | 時刻 |
|---|---|
| 日沒 | **18:31** |
| 市民薄暮終了（藍調時刻結束、天色全暗） | **18:55** |
| 常夜燈點燈 | 約 **18:00 前後**（黃昏時點亮，官方未公告確切時刻） |

| 時間 | 動作 |
|---|---|
| 07:00 | 飯店出發，步行至尾道站 |
| 07:1x | 尾道站 **2 番月台**搭 JR 山陽本線往福山（約 20–25 分，¥410） |
| **07:40** | 福山站**南口 5 號站牌**搭鞆鉄巴士鞆港行（¥620） |
| **08:17** | 抵達鞆港，展開一日散策 |
| 18:00–18:55 | **常夜燈夕景**：點燈後以日沒與藍調時刻為背景，適合在雁木（港邊石階）觀賞 |
| 19:00–19:20 | 步行回鞆港站牌（常夜燈就在旁邊，約 2–3 分，留餘裕） |
| **19:28** | 鞆港發，**20:00** 抵福山駅前 |
| 20:00–20:20 | 步行至 JR 在來線改札（約 5 分），有 23 分鐘緩衝 |
| **20:23** | 福山發 JR 山陽本線，約 **20:45** 抵尾道 |
| 21:00 左右 | 步行回住宿（約 10 分） |

**單日交通費估算（單人）：** JR 來回 ¥820 ＋ 巴士來回 ¥1,240（以鞆港計）＝ **約 ¥2,060**。

> ⚠️ **09/04 是尾道最後一晚，隔天 09/05 早上 07:00 就要離開住宿。** 21:00 才回到房間，打包只剩一個晚上的尾巴，**行李務必在 09/04 出門前就整理到「回來只要塞當天用品」的程度**。

> 📌 **晚餐不在鞆之浦吃，回尾道後解決（已決定）。** 19:28 離開、20:45 抵尾道，鞆之浦的餐飲店多數 17:00–18:00 就打烊，尾道本通商店街平日也多在 20:00–21:00 收，因此不排正式晚餐。**住宿旁的 AEON STYLE 尾道營業到 22:00**，21:00 回到住宿仍來得及採買；再晚則走尾道站的 7-11（24 小時）。這也順便把隔天早餐一起買好。

> 📌 **保險班次是 20:18（尾道約 21:22 抵達）。** 因為晚餐靠超市採買，這班**仍趕得上 22:00 打烊的 AEON STYLE 尾道**，想在鞆之浦多待到天全黑就用它，代價是打包時間再少 40 分。**只有 21:18 末班（22:23 抵尾道）會錯過超市**，那時只剩尾道站的 7-11（24 小時）。
