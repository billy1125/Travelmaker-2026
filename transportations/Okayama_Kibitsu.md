# 岡山站 → 吉備津站・吉備津神社 指南

## 路線概覽

| 項目 | 內容 |
|------|------|
| 路線 | **JR 吉備線（愛稱「桃太郎線」）**，岡山 → 総社 |
| 使用區間 | 岡山站 → **吉備津站**（第 5 站） |
| 所需時間 | **約 15–18 分** |
| 車資 | 約 **¥210**（IC 卡可用；出發前確認是否調整） |
| 班距 | **白天約每小時 1–2 班**，最疏處有近 1 小時空窗 |
| 月台 | 岡山站 **9・10 番**（津山線・吉備線共用，出發前確認當日月台） |
| 出站後 | 吉備津站 → [吉備津神社](https://www.google.com/maps/search/?api=1&query=吉備津神社) **步行約 10 分**（松並木參道） |

> ⚠️ **這條線是非電化單線，班次稀疏，去回都要先對時刻。** 不能像山陽本線那樣隨到隨搭——錯過一班可能等 30–60 分鐘，而 09/07 下午還要趕回岡山採買。

> ⚠️ **岡山站的吉備線月台在 9・10 番**，與宇野線（5–8 番）、山陽本線（1–4 番）都不同。09/06 直島日走的是 5–8 番，不要記混。

## 吉備津神社

| 項目 | 內容 |
|------|------|
| 拝観時間 | **05:00–18:00** |
| 參拜費用 | **免費** |
| 公休 | **全年無休** |
| 授与所（御守・御朱印） | 09:00–16:00 |
| 祈祷受付 | 09:00–14:30 |
| 電話 | 086-287-4111 |

看點：

- **國寶本殿・拝殿**：日本唯一的「吉備津造（比翼入母屋造）」，1425 年重建
- **360 m 長回廊**：沿山勢起伏的木造迴廊，岡山縣指定重要文化財，最經典的攝影點
- **御釜殿**：「鳴釜神事」的舞台，也是上田秋成《雨月物語》〈吉備津の釜〉的取材地

> ⚠️ **回廊與參道多為戶外**，雨天體驗打折，9 月初白天仍可能超過 30°C，帶水與遮陽。
