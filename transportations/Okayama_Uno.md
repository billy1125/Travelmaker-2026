# 岡山站 → 宇野站・宇野港（往直島）指南

## 路段概覽

| 項目 | 內容 |
|------|------|
| 路段 | [JR 岡山站](https://www.google.com/maps/search/?api=1&query=JR岡山駅) → [JR 宇野站](https://www.google.com/maps/search/?api=1&query=JR宇野駅) → [宇野港](https://www.google.com/maps/search/?api=1&query=宇野港+玉野市) → 直島[宮浦港](https://www.google.com/maps/search/?api=1&query=直島宮浦港) |

| 所需時間 | 鐵路約 **50–60 分**（直通車較快，轉乘車較久）＋ 步行 5 分 ＋ 渡輪 **20 分** |
| 鐵路車資 | 岡山 → 宇野 **約 590 円**（IC 卡可用） |
| 渡輪票價 | 宇野港 → 宮浦港 **大人 370 円・兒童 190 円**（單程） |
| 班次密度 | 鐵路白天約**每小時 1 班**；渡輪一日 **14 班**（另有旅客船 3 班） |
| 岡山站月台 | **5–8 番**（瀨戶大橋線・宇野線月台） |

> ⚠️ **注意 5 番與 7 番月台位於 6・8 番月台的前端延伸段**，清晨趕首班車時容易走過頭，詳見 `OkayamaStation.md`。

## JR 岡山 → 宇野

- 路線正式名稱為**宇野線**（暱稱「宇野みなと線」）；岡山～茶屋町這一段與瀨戶大橋線共用軌道
- **部分班次為「宇野行」直通**，其餘需**在茶屋町轉乘**。搭車前先確認車頭方向幕是「宇野」還是「児島／高松」
- 往高松、兒島方向的列車（含快速マリンライナー）**不會到宇野**，在茶屋町分歧，切勿搭錯
- **ICOCA 等全國相互利用 IC 卡全線可用**（茶屋町～宇野區間自 2019/03 起納入）
- 岡山～茶屋町間另有只停大元、備前西市、妹尾的快速列車

> ⚠️ 白天班距約 1 小時，**錯過一班影響很大**。清晨首班與傍晚回程班次務必出發前查好（連結見文末）。

## 宇野站

| 項目 | 內容 |
|------|------|
| 地址 | 岡山縣玉野市築港 1-1-1 |
| みどりの窓口 | **無** |
| みどりの券売機プラス | **有**（04:45–23:00，可視訊客服對應 08:00–20:00） |
| 改札 | ICOCA 對應，設有改札口對講系統 |
| 到宇野港 | 步行約 **5 分鐘** |

**投幣式置物櫃**

| 位置 | 尺寸 | 費用 | 個數 |
|------|------|------|------|
| **改札內**（進站後左手邊、廁所前） | 小 | 400 円 | 10 |
| 同上 | 中 | 600 円 | 20 |
| 同上 | 大 | 800 円 | 11 |

- **只收現金，不能用 IC 卡**；兌幣機接受 500 円與 1,000 円
- 大型櫃可放一般尺寸行李箱；最長寄放 3 天
- ⚠️ **櫃子在改札「內」**，出站後才想寄放的話需另買入場券才能進去

**人工行李寄放：** 出改札後右手邊的[玉野觀光案內所](https://www.google.com/maps/search/?api=1&query=玉野市宇野港観光案内所)，**09:00–17:00**，小件 300 円・大件 500 円，不需入場券。

> ⚠️ **宇野港渡輪碼頭沒有置物櫃**，要寄放行李只能在宇野站或觀光案內所處理。

> ⚠️ 票價已調整為 **370 円**（`days/0830.md` 舊記載為 ¥290，以官方現行公告為準）。

### 乘船處

**宇野港側**

- **渡輪碼頭**（主要）與**旅客船乘船處**是**兩個不同的地方，相距步行約 3 分鐘**，買票前先確認搭的是哪一種船
- JR 宇野站步行約 5 分鐘可達渡輪碼頭；官網另有從宇野站到旅客船售票處的無障礙路線說明
- ⚠️ **宇野港碼頭沒有投幣式置物櫃**，行李需在宇野站或玉野觀光案內所處理（見上一節）

**直島側**

- **宮浦港**：直島主要門戶，[赤南瓜](https://www.google.com/maps/search/?api=1&query=草間彌生+赤かぼちゃ+直島)就在碼頭旁；町營巴士總站設於此，往本村與 Benesse 地區都從這裡發車
- **本村港**：緊鄰町營巴士「直島港（本村）」站牌，出港即是家 Project 所在的本村地區

### 購票與搭乘

| 項目 | 內容 |
|------|------|
| 預約 | **不接受預約，也無事前販售**，一律現場先到先上 |
| 滿船時 | 官方說明「滿船則安排搭下一班」，建議提早到場 |
| 宇野～宮浦售票 | **窗口販售，05:30–20:25** |
| 宇野～本村售票 | 僅 11:55 本村行、13:30 宮浦行於開航前約 20 分開始售票，**其餘班次由船員在船上收費** |
| 付款 | 窗口為**現金**；官方 FAQ 另註明高松港・宮浦港・宇野港設有**售票機可刷信用卡** |

- 停航與否公告於官網「運航狀況」頁；8 月底至 9 月初為颱風季，出發當天務必確認
- ⚠️ 旺季（瀨戶內國際藝術祭期間、連假）宮浦港排隊人潮多，**回程尤其容易滿船**，建議提早一班到碼頭

## 本次行程使用規劃（08/30 Day 3・直島一日遊）

| 時間（估算） | 動作 |
|---|---|
| 06:00 | 飯店（岡山站東口）出發，步行約 5 分至岡山站 |
| 06:10 左右 | 岡山站 **5–8 番月台**搭宇野線（確認為「宇野」方向；非直通則於茶屋町轉乘），約 50–60 分，¥590 |
| 07:00 左右 | 宇野站下車，步行約 5 分至宇野港碼頭 |
| 07:15 左右 | 窗口購票（大人 ¥370）搭渡輪，約 20 分 |
| 07:35 左右 | 抵達直島宮浦港 |
| 16:40 左右 | 宮浦港 → 宇野港（回程末班約 18:00 前，須先確認） |
| 17:10 左右 | 宇野站搭 JR 回岡山，約 50–60 分 |

**單日交通費估算（單人）：** JR 來回 ¥1,180 ＋ 渡輪來回 ¥740 ＝ **約 ¥1,920**（不含島內巴士）。

**回程替代方案：** 若當天結束時人在**本村**，可直接從本村港搭旅客船回宇野（同樣 370 円、約 20 分），省下回宮浦的巴士時間；但**本村航路一天只有 5 班**，部分班次在船上才收費，需事先查好時刻。

> ⚠️ 回程是全日最需要注意的環節：**渡輪末班與 JR 末班都不密集**，離開直島的時間要以「趕上預定渡輪」回推，不要卡在美術館閉館時間。
