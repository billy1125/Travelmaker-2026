# 岡山桃太郎機場 ↔ 岡山站 利木津巴士指南

## 路線概覽

| 項目 | 內容 |
|------|------|
| 路線 | 岡山桃太郎機場（2號站牌）↔ 岡山站西口（21號站牌） |
| 所需時間 | 約 **30 分鐘**（視交通狀況，山路段可能延誤） |
| 票價（岡山站） | 大人 **1,000 円**・兒童 **500 円** |
| 票價（倉敷站） | 大人 **1,400 円**・兒童 **700 円** |
| 預約 | **不需預約**，直接前往站牌搭車 |
| 營運公司 | 岡電巴士・中鉄巴士（共同運行） |
| 班次頻率 | 約每 30～60 分鐘一班（視時段，詳見時刻表） |

> ⚠️ 票價資訊以出發前官方公告為準。部分中途站（體育中心前／スポーツセンター前・岡山大学筋等）票價較低（950 円）。

## 站牌位置

- **機場出發**：到達大廳出口外右手邊，[2號站牌](https://www.google.com/maps/search/?api=1&query=岡山桃太郎空港バス乗り場)，出門即可看到售票機與工作人員
- **岡山站出發**：岡山站西口，[21號站牌](https://www.google.com/maps/search/?api=1&query=岡山駅西口バスのりば)（候車室內設有售票機與廁所，有座位）

> ⚠️ 岡山站西口都是同一個地方上下車，到現場記得確認一下。

## 付款方式

| 方式 | 說明 |
|------|------|
| 全國交通系 IC 卡 | ICOCA、Suica、HARECA 等，上下車時感應 |
| 售票機（機場 / 岡山站西口候車室） | 現金、信用卡（**僅感應式**）、電子錢包、QR 碼 |
| 車內現金 | 中途站上車者可用現金，整理券制 |

> 建議在售票機提前購票，下車時將票交給司機。

## 搭乘流程（機場出發）

1. 出境後往右走，機場大門外即為巴士乘車區
2. 在售票機選擇目的地（岡山站 / 倉敷站）購票
3. 將大行李交給現場工作人員（**有專人幫忙放置行李艙**）
4. 對號上車等待發車

> 工作人員親切，流程非常直覺。若不確定，跟著人群走即可。

## 國際線加班車（重要）

機場針對 **台北・高雄・首爾・上海** 等國際航班，會在落地後加開臨時接駁巴士，**不列入一般時刻表**。

- 本行程去程 **IT214**（台北 → 岡山，15:05 落地）即屬適用航班
- 落地後請盡快通關（入境審查 + 提領行李 + 海關），直接前往 2 號站牌
- 滿車時會加開備用車輛

## 本次行程使用規劃

### Day 1（08/30）— 機場 → 岡山站

| 時間（估算） | 動作 |
|---|---|
| 15:05 | IT214 落地 |
| 15:05–15:50 | 入境審查（國際線）、提領行李、海關通關（預留 45 分鐘以上） |
| 15:50 左右 | 出到達大廳，前往 2 號站牌購票 |
| 16:00 左右 | 搭乘利木津巴士（IT214 台北航班加班車，或下一班定期車） |
| 16:30 左右 | 抵達[岡山站西口](https://www.google.com/maps/search/?api=1&query=JR岡山駅)，前往飯店 Check-in |

### Day 10（09/08）— 岡山站 → 機場（IT215，15:55 起飛）

| 時間 | 動作 |
|---|---|
| 12:40 | 移動至 21 號站牌候車 |
| **12:55** | 搭乘利木津巴士出發（07–08 月版時刻表，唯一符合班機時間的班次） |
| **13:25 左右** | 抵達岡山桃太郎機場，辦理報到、出境（距起飛約 2.5 小時） |
| 15:55 | IT215 起飛 |

> ⚠️ **注意** ⚠️
> - **回程不會像去程一樣視人潮加班**，必須嚴格依定期班次搭乘。
> - 岡山站發車 **12:55 之後直到 14:50 沒有班次**；14:50 約 15:20 抵機場，距 15:55 起飛僅 35 分鐘，**趕不上報到截止**。
> - 因此 **12:55 是唯一可行班次**，回推需在 12:30 前抵達岡山站、11:10 前從尾道站出發。
> - **9 月版時刻表尚未公告**，出發前務必重新確認；若 12:55 班次異動，需連帶調整當日退房與出發時間。

### 從尾道到岡山站的兩種走法（09/05）

| 方式 | 路線 | 車程 | 費用 | 說明 |
|------|------|------|------|------|
| **A. JR 在來線（主要方案）** | 尾道站 → 岡山站（山陽本線） | 約 70–80 分 | 約 **¥1,340** | 直達不轉車，09:20 出發約 10:40 抵岡山，採買時間充裕 |
| **B. 新幹線こだま（備援）** | 尾道站 →（巴士約 15 分）→ 新尾道站 →（こだま）→ 岡山站 | 巴士 15 分＋新幹線 34 分＋轉乘等候 | 巴士 ¥190 ＋ 車資 ¥1,340 ＋ 自由席特急券 ¥1,760 ＝ 約 **¥3,290** | 比在來線快約 40 分，適合**睡過頭或在來線延誤**時追趕 12:55 巴士 |

- 方案 B 要多算「尾道站 → 新尾道站」的巴士班次（尾道巴士（おのみちバス）／中國巴士（中国バス）），**新尾道站只停こだま，班次不密**，臨時決定前先查兩段時刻
- 若住宿處出發，步行至新尾道站約 20 分，可省下巴士段但要拖行李走上坡

> ⚠️ 方案 B 的成本約為方案 A 的 2.5 倍，且多一次轉乘。**沒有延誤時沒有採用的理由**——提早退房、走方案 A 就能有近 2 小時的採買時間。
