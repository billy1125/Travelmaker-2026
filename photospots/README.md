# 攝影景點總覽

回上層：[README.md](../README.md)｜[itinerary.md](../itinerary.md)

> **這一層只記錄拍攝資訊，不改動行程。** 每個檔案都有「與本次行程的對應」一節，標明哪些點落在既有動線上、哪些需要額外加排；**要把拍攝點排進行程，仍須經討論後由 `/update-itinerary` 寫入 `days/`**。

## 每份檔案包含什麼

- **拍攝點清單**：位置、距車站步行時間、Google Maps 連結、周邊地標、構圖重點
- **與本次行程的對應**：哪一天順路、幾點最適合、是否需要額外加排
- **待查證**：尚未確認的光線方向、潮汐、班距、正式名稱等
- **參考來源**：並標註哪些來源的資料已過期或需打折看

## 新增或修改

**`photospots/` 查證後可直接更新，不需經 `/update-itinerary`**——這是它與 `days/`、`transportations/` 最大的差別。但把拍攝點實際排進行程仍要走 `/update-itinerary`。新增或移除檔案時，這份總覽與 [`../README.md`](../README.md) 都要同步。
